Each coloured header is a layer; the boxes beneath it are that layer’s components. Indented boxes are parts of the component directly above them.

Blue boxes are extensions to the original framework: memory, verification by an LLM judge, the interfaces layer, and observability, which spans every layer. The orange Loop runs outside the harness; Verification feeds it, and each pass comes back to be verified again. The amber mark shows what the harness can rewrite between runs — instructions, memory, tools, workflow, and lifecycle hooks.
